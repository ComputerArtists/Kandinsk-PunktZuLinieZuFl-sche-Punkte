„Vom Punkt aus“
Eine Sammlung generativer Processing-Skripte
100 % erstellt von Grok (xAI) im Dezember 2025
Thema: Wassily Kandinsky – Punkt und Linie zu Fläche (mit Schwerpunkt Punkt/Kreis)
Inhalt dieser Sammlung (jeweils ein .pde-File):

kandinsky_inspired.pde – Statische, farbige Komposition im Geist von Komposition VIII
points_and_lines_minimal.pde – Ruhige Netzwerke aus Punkten und zarten Verbindungen
connecting_dots_animated.pde – Schwebende Punkte mit dynamischen Linien (inkl. Export-Modus)
circles_only_four_modes.pde – Vier völlig unterschiedliche Bilder, nur aus Kreisen
rhythm_of_circles.pde – Hypnotische, polyrhythmische Kreis-Animation
graphical_score_circles.pde – Abstrakte, spielbare grafische Partitur aus Kreisen und Punkten
random_points_classic.pde – Der allererste Punkteschwarm (für Vollständigkeit)

Bedienung (gemeinsam für fast alle Skripte):

Leertaste → neue Variation / neue Komposition
s oder S → aktuellen Frame als PNG speichern
r → bei manchen Skripten startet/stopt PNG-Sequenz-Export
Pfeiltasten hoch/runter → Tempo ändern (bei animierten Skripten)

Technische Hinweise

Alle Skripte laufen mit Processing 4.x ohne zusätzliche Bibliotheken.
Für 4K-Ausgabe einfach in size(3840, 2160); ändern (oder size(3840, 2160, P2D); für mehr Geschwindigkeit).
Exportierte Bilder landen im Sketch-Ordner (bzw. im Unterordner „export“, falls vorhanden).
